# CP3406 Assessment 3 Final Checklist

Use this before exporting the Android Studio project.

- [ ] App opens without a crash on the emulator/device.
- [ ] Landing Page works and can start a quiz.
- [ ] Quiz Activity can fetch online questions.
- [ ] Offline fallback works when the online request fails.
- [ ] Easy, Medium and Hard settings work.
- [ ] Question-count setting works from 5 to 15.
- [ ] Answer-feedback setting changes quiz behaviour.
- [ ] Completing a quiz stores an attempt in Room.
- [ ] Statistics screen shows attempt count, average, best and recent attempts.
- [ ] Clear Learning History removes stored attempts.
- [ ] Unit tests pass.
- [ ] Compose GUI test passes on an emulator/device.
- [ ] Test the UI with larger Android font size.
- [ ] Test both light and dark system themes.
- [ ] Check privacy/transparency wording matches the actual app behaviour.
- [ ] Make genuine, regular GitHub commits showing your development progress.
- [ ] Add a clear README to GitHub.
- [ ] Write the approximately 1000-word, two-page self-reflection using all Gibbs stages: Description, Feelings, Evaluation, Analysis, Conclusion and Action Plan.
- [ ] Explain how your Assessment 2 ethical research / ACS principles affected actual design decisions.
- [ ] Include the required Declaration of AI-Generated Material for any GenAI assistance used.
- [ ] Export the final Android Studio project as a ZIP.
- [ ] Export the self-reflection as PDF.
- [ ] Submit the GitHub repository link and share it with the lecturer / subject coordinator as required.
